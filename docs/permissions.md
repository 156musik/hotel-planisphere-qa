# Permissions

## User Types

| User Type | Description | Notes |
|-----------|-------------|-------|
| 未ログイン | ログインセッションを保持していないユーザー | ログインが必要な機能は利用できない | 
| 一般会員 | ユーザーランクが「一般」に設定されているユーザー | - |
| プレミアム会員 | ユーザーランクが「プレミアム」に設定されているユーザー | ユーザーランクの付与方法は要確認 |
